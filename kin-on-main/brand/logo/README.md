# Kin on Main logo

| File | Use |
|---|---|
| `kin-on-main-logo-cream.png` | **Primary.** The app, receipts, counter cards, window decals, print |
| `kin-on-main-logo-navy.png` | Dark backgrounds only: social, signage, dark mode |
| `../../public/brand/kin-on-main-mark.svg` | Storefront mark, full color (app icon, favicon) |
| `../../public/brand/kin-on-main-mark-{indigo,cream,black}.svg` | One-color mark for decals, receipts, stamps, photos |

**Rules**
- Lead with cream. Use navy only when the background is already dark.
- Write "Kin *on* Main", with "on" lowercase and in italic brick (gold on navy).
- Below 32px, use the storefront mark alone. Small sizes drop the "open" sign to a gold bar and the sun to three rays.
- On photos or colored backgrounds, use a one-color mark.
- Leave clear space around the logo at least the height of the awning.
